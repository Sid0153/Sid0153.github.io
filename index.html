Cloud security · 2026

CloudSentinel: AWS Security Scanner

A read-only AWS security scanner with a web dashboard. It discovers EC2, S3, IAM and CloudTrail resources, checks them against security rules, and gives every finding an explainable 0–100 risk score.

  • 8 rules: SSH/RDP open to the internet, public or unencrypted S3 buckets, console users without MFA, over-broad IAM permissions, missing CloudTrail logging.
  • Honest coverage: a denied API call is reported as "could not check", never as "secure".
  • Findings tracked across scans, with analyst triage, role-based access and an append-only audit log.

Security operations · 2026

SentinelX: Threat Detection & Incident Platform

A security operations platform: it ingests security logs, detects attacks with explainable rules, correlates alerts into incidents, and gives analysts one place to investigate, hunt and record what they did.

  • Ingests 5 log formats (Linux auth.log, Windows Security events, nginx/Apache, JSON) and keeps every raw record.
  • 9 YAML detection rules (brute force, password spraying, port scans, sudo root shells…) mapped to MITRE ATT&CK, each explaining itself in a sentence.
  • Alerts correlated into incidents with a reason per link; threat hunting, a rule playground, TOTP 2FA and a hash-chained audit log.
